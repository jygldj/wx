🎯 任务目标
在现有的“铜钱摇卦”功能基础上，增加一个“手动输卦”模式。用户可以手动选择六个爻的阴阳动静，系统能自动排盘，并最终跳转到解卦页面。
🛠️ 核心要求
模式切换：在页面顶部增加模式切换按钮，用户可以在“铜钱摇卦”和“手动输卦”之间无缝切换。
数据统一：无论哪种模式，最终生成的卦象数据（yaoResults 和 dongStatus 数组）格式必须完全一致，以确保后续的排盘、解卦逻辑可以完美复用。
代码复用：严禁修改任何现有的排盘、解卦、数据存储相关的核心逻辑。你的工作是在现有逻辑之上增加一个“输入层”。
📝 具体修改步骤
第一步：修改 HTML 结构
在 <div class="nav-bar">...</div> 导航栏下方，新增一个用于模式切换的按钮栏。
在 <div class="coin-area" id="coinArea">...</div> 铜钱区域下方，新增一个用于手动输入爻象的面板 div#inputArea。该面板默认隐藏 (style="display: none;")。
第二步：新增 CSS 样式
在 <style> 标签内，新增以下样式，用于美化模式切换按钮和手动输入面板的每一行。
.mode-switch-bar：用于布局切换按钮。
.mode-btn：切换按钮的样式，包含默认、悬停和激活（.active）状态。
.yao-input-row：手动输入面板中，每一行（代表一个爻）的样式。
第三步：修改 JavaScript 逻辑
这是最关键的一步，请在 <script> 标签内，resetAll 函数之后、事件绑定之前的位置，新增以下代码：
定义常量：创建一个 YAO_OPTIONS 数组，定义“少阳”、“少阴”、“老阳”、“老阴”四种爻象的值、文本、符号、阴阳属性和动静属性。
获取DOM引用：获取新模式按钮、新面板以及面板内部容器的引用。
编写 createYaoInputs 函数：
功能：动态生成6个输入行，从下往上（初爻到上爻）。
每一行包含：爻位标签（如“第1爻”）、一个 select 下拉框（包含四种爻象选项）、一个用于实时预览爻象符号的 span。
为每个 select 添加 change 事件监听器，当用户选择时，实时更新旁边的预览符号。
编写 switchMode(isCoinMode) 函数：
功能：根据 isCoinMode 参数，切换“铜钱摇卦”和“手动输卦”两种模式的界面显示。
切换到“手动输卦”时，需禁用摇卦相关按钮，并启用“确认排盘”按钮。
编写 confirmInput() 函数：
功能：读取用户在6个下拉框中的选择。
根据选择，生成与摇卦模式格式完全相同的 yaoResults (1为阳, 0为阴) 和 dongStatus (true为动, false为静) 数组。
设置 currentStep = 6，并直接调用现有的 completeAndDisplay() 函数进行排盘。
绑定事件：
为“铜钱摇卦”按钮绑定点击事件，调用 switchMode(true)。
为“手动输卦”按钮绑定点击事件，调用 switchMode(false)。
为“确认排盘”按钮绑定点击事件，调用 confirmInput()。
初始化：在脚本末尾调用一次 createYaoInputs() 以生成输入框。
✅ 验收标准
页面加载后，默认显示“铜钱摇卦”模式，功能正常。
点击“手动输卦”按钮，界面平滑切换到输入面板，铜钱区域隐藏。
在输入面板中，可以顺利为6个爻位选择阴阳动静，并有实时符号预览。
点击“确认排盘”后，能正确生成卦象，显示本卦和变卦，且世应、动爻标记准确。
点击“释卦”按钮，能成功跳转到 jiegu.html 页面，并正确显示解卦内容。
在两种模式之间来回切换，所有功能和界面状态均正常，无报错。
